# Emotion Recognition Feedback System

A real-time, non-invasive system for detecting students' psychological states using micro-expressions.

## Project Overview
This project aims to develop a self-assisted detection system for students' psychological status. By utilizing micro-expression research and computer vision technologies, the system captures potential emotional and mental states in real-time. It is designed to facilitate early warning of psychological issues, allowing for timely intervention and support for students' mental health.

## Tech Stack
- **Programming Language**: Python
- **Computer Vision**: OpenCV, DeepFace
- **Deep Learning**: TensorFlow
- **Data Processing**: NumPy, Pandas
- **LLM Integration**: Ollama

## Files
- `emotion_feedback_ollama.py`: Main application logic.
- `lct.py`: Core algorithm implementation for emotion recognition.
- `requirements.txt`: Python dependencies required to run the project.
